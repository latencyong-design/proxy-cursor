# Contributing

Thanks for helping improve proxy-cursor.

## Good First Issues

Good starting points are:

- Windows compatibility reports;
- clearer setup docs;
- safer defaults for local configuration;
- better diagnostics for ProxyBridge and Cursor startup failures.

## Before Opening an Issue

Please include:

- Windows version;
- Cursor version;
- ProxyBridge version;
- proxy type and local port, without credentials;
- whether `scripts\Status-CursorProxyBridge.bat` shows a running task/process;
- the exact error text, with private paths or proxy credentials redacted.

## Pull Requests

Keep changes narrow and testable. For script changes, include the command you
used for validation and explain any compatibility impact for existing users.
